# Portal del cliente — Agente IA 360

Página donde cada negocio (cliente) entra con su usuario para:
- Ver el estado de su WhatsApp y escanear el QR para reconectarlo.
- Llenar el formulario de configuración de su asistente (la IA genera el prompt y el super-admin lo aprueba).

## Variables de entorno (EasyPanel → Environment)
```
SUPABASE_URL=https://core8flow-supabase.6hpfrc.easypanel.host
SUPABASE_ANON_KEY=<ANON_KEY de Supabase>
N8N_URL=https://core8flow-n8n.6hpfrc.easypanel.host
```
Nunca pongas aquí la SERVICE_ROLE_KEY.
